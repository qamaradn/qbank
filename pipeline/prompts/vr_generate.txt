DIFFICULTY RULES — APPLY TO ALL 10 QUESTIONS

VOCABULARY LEVEL:
- Use everyday vocabulary a Year 7-9 student will likely know
- Good examples: brave, honest, generous, curious, stubborn, cheerful,
  ancient, fragile, loyal, swift, cruel, timid, clumsy, precise, vague,
  triumph, defeat, expand, reduce, similar, opposite, sequence, pattern
- Avoid sophisticated/rare words (reticent, loquacious, intransigent,

DISTRACTOR QUALITY — most important rule:
- All 3 wrong options must be genuine vocabulary words
- Wrong options must be same part of speech as the correct answer
- At least 2 distractors must be close enough that a weak student picks them
- Never make the correct answer obvious by process of elimination alone
- For analogies: all 4 options must fit the surface reading of the question
  but only one fits the precise relationship

ANALOGY RELATIONSHIPS — use these specific types, vary across batch:
- function (architect:building :: composer:symphony)
- degree/intensity (warm:hot :: content:ecstatic)
- part-to-whole (chapter:novel :: verse:poem)
- category-member (oak:tree :: sonnet:poem)
- cause-effect (drought:famine :: exercise:fitness)
- antonym-pair (courage:cowardice :: generosity:greed)
- tool-user (scalpel:surgeon :: chisel:sculptor)
- characteristic (miser:frugal :: orator:eloquent)

ODD ONE OUT RULES:
- The grouping logic must be clearly defensible in one sentence
- All 4 options must look like they belong — the odd one out must require
  real thought to identify
- Never use a grouping so obvious a Year 5 student would spot it instantly
- Good groupings: subtle semantic distinctions, word class traps,
  connotation differences, degree of intensity

SENTENCE COMPLETION RULES:
- Sentence must have academic or intellectual content — not trivial
- Exactly one answer must be unambiguously correct from context
- The correct word should not be the only one that grammatically fits
- Use Australian English spelling throughout

WORD PATTERN / CODE RULES:
- The rule must be discoverable from the example given in the question
- Rule complexity: appropriate for Year 9-10 (multi-step is fine)
- Always provide one worked example within the question stem

LOGICAL DEDUCTION RULES:
- Can use invented words (fiys, giws, dyls) to prevent prior knowledge
- Premises must be valid — no ambiguous or trick logic
- Exactly one answer must follow necessarily from the premises
- Do not require knowledge beyond what is stated in the question
